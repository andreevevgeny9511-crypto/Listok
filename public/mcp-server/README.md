# ListOk CRM MCP Server

MCP-сервер для интеграции ListOk CRM с AI-агентами (Claude, Cursor, Codex, Битрикс24 и др.)

## Установка

### Локальная установка (для Claude Desktop, Cursor, Codex)

1. Скачайте папку `mcp-server/` на ваш компьютер
2. Установите зависимости:
   ```bash
   cd mcp-server
   npm install
   ```
3. Настройте переменные окружения:
   - `LISTOK_DOMAIN` — ваш домен ListOk CRM (например, `an7236.listokcrm.ru`)
   - `LISTOK_TOKEN` — Bearer-токен из настроек приложения

### Серверная установка (для Битрикс24)

1. Загрузите папку `mcp-server/` на ваш сервер в папку `/Listok/mcp-server/`
2. Убедитесь, что PHP установлен и работает
3. MCP-сервер будет доступен по адресу: `https://ваш-домен/Listok/mcp-server/`

## Подключение к AI-клиентам

### Claude Desktop

Добавьте в `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "listok-crm": {
      "command": "node",
      "args": ["/путь/к/mcp-server/index.js"],
      "env": {
        "LISTOK_DOMAIN": "an7236.listokcrm.ru",
        "LISTOK_TOKEN": "ваш_токен"
      }
    }
  }
}
```

### Cursor IDE

Добавьте в `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "listok-crm": {
      "command": "node",
      "args": ["/путь/к/mcp-server/index.js"],
      "env": {
        "LISTOK_DOMAIN": "an7236.listokcrm.ru",
        "LISTOK_TOKEN": "ваш_токен"
      }
    }
  }
}
```

### Битрикс24

1. Откройте AI-ассистент в Битрикс24
2. Перейдите в настройки → «Подключения MCP»
3. Добавьте новый сервер:
   - URL: `https://ваш-домен/Listok/mcp-server/`
   - Токен: ваш Bearer-токен из настроек приложения

## Доступные инструменты

- **Клиенты**: поиск, создание, редактирование клиентов
- **Абонементы**: оформление, заморозка, разморозка абонементов
- **Занятия**: создание занятий, управление расписанием
- **Записи**: запись клиентов на занятия, отмена записей
- **Посещения**: отметка посещений, отмена посещений
- **Платежи**: просмотр платежей, фильтрация по датам
- **Группы**: управление группами и направлениями
- **Сотрудники**: просмотр преподавателей и менеджеров

## Требования

- Node.js 18+ (для локальной установки)
- PHP 7.4+ (для серверной установки)
- HTTPS (обязательно для Битрикс24)
